Romestead Cheat Menu
https://github.com/Keha-Chester/Romestead_Mod_Menu

INSTALL
1. Close the game.
2. In Steam, right-click Romestead > Manage > Browse local files.
3. Extract the archive into that folder, so that you get romestead\CheatMenu\.
4. Double-click CheatMenu\Install.bat
   (if Windows asks whether to run it, choose Run / More info > Run anyway).
5. Start the game, load a world and press Ctrl+0.

If Ctrl+0 stops working after a game update or "Verify integrity of game files",
run Install.bat again.

UNINSTALL
Run CheatMenu\Uninstall.bat, then delete the CheatMenu folder.
Do not delete the folder first: the game would fail to start. If that has already
happened, use Steam > Romestead > Properties > Installed Files > Verify integrity of game files.

PROBLEMS
Attach CheatMenu\RomesteadCheatMenu.log when you report a problem.


УСТАНОВКА
1. Закройте игру.
2. В Steam: правый клик по Romestead > Управление > Просмотреть локальные файлы.
3. Распакуйте архив в эту папку, чтобы получилась папка romestead\CheatMenu\.
4. Запустите CheatMenu\Install.bat двойным кликом
   (если Windows спросит, запускать ли файл, выберите «Выполнить» / «Подробнее» > «Выполнить в любом случае»).
5. Запустите игру, загрузите мир и нажмите Ctrl+0.

Если после обновления игры или «Проверки целостности файлов» Ctrl+0 перестал
работать, снова запустите Install.bat.

УДАЛЕНИЕ
Запустите CheatMenu\Uninstall.bat, затем удалите папку CheatMenu.
Не удаляйте папку раньше: иначе игра не запустится. Если это уже случилось:
Steam > Romestead > Свойства > Установленные файлы > Проверить целостность файлов игры.

ПРОБЛЕМЫ
Если что-то не работает, приложите к сообщению файл CheatMenu\RomesteadCheatMenu.log.
